# פרדוקס השקרן באולם המשפט

עמוד אינטראקטיבי סאטירי שממחיש את פרדוקס השקרן בעזרת תרשים זרימה:
שני מחנות פוליטיים, אולם המשפט, ותיק 4000.

**לצפייה באתר:** https://yishulman-svg.github.io/liar-paradox-court/

אפשר לבחור מחנה, לעבור שלב־שלב בלולאה, להציג את שני המחנות זה מול זה, ולהפעיל «פתרונות חילוץ» פילוסופיים (אפימנידס, טרסקי, קריפקי) ששוברים את הלולאה.
